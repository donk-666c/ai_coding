# 素材目录

**文件名必须完全一致**——代码里的路径是写死的，换名字不会自动找到。

## 可选的用户素材

这两张图都**不随仓库分发**（避免第三方版权素材进公开仓库），游戏和测试都不依赖它们。
自己放进来就能启用对应功能：

| 文件 | 放进来之后 |
|---|---|
| `wallpaper.jpg` | 通关奖励页显示壁纸，并启用「保存壁纸」按钮 |
| `sponsor-qr.jpg` | 赞助页显示收款码 |

> 收款码这条路径仍在代码里（游戏画面开了 `pixelArt`，最近邻采样会把二维码变马赛克，
> 所以它必须走 DOM 层）。以后若要启用，放的图别二次压缩——压缩过的码手机扫不出来，
> 判定标准只有一个：**真的拿手机扫一次**。

素材缺失时，界面上会显示占位提示，游戏流程不受影响。

**扩展名要跟着内容走**：这两张本来就是 JPEG，所以叫 `.jpg`。改成 `.png` 不会让画质变好——
有损压缩丢掉的信息回不来，只会让文件变大。浏览器和 WebView 判断图片格式靠读文件内容而非扩展名，
所以就算名字写错也照样显示；但玩家保存壁纸时，存下来的文件扩展名会直接沿用这里的名字，
写错了某些看图软件会报「文件损坏」。

## 游戏素材

| 文件 | 来源 |
|---|---|
| `tiles.png` | [Kenney Pixel Platformer](https://kenney.nl/assets/pixel-platformer) 的 `tilemap_packed.png`，20 列 × 9 行 × 18px |
| `chars.png` | 同一素材包的 `tilemap-characters_packed.png`，9 列 × 3 行 × 24px |
| `Kenney-License.txt` | 原始许可证（CC0，署名非必需，但留着以示出处） |

两张图都是 **packed 版**（格子之间没有间隔），所以 `load.spritesheet()` 不需要 `spacing` / `margin`。
帧号 = 行 × 列数 + 列。要改帧号，先用图片查看器打开数一遍，再改 `src/game/config.ts` 的 `FRAMES`。
